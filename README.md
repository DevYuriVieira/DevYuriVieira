## 🚀 About Me

Full-Stack Developer focused on **Java (Spring Boot)** and **React**, with experience building scalable web applications, REST APIs, and modern frontend interfaces. Also work with **React Native** for mobile.

Solid foundation in **Python (Django)**, relational databases, software architecture, authentication and authorization with Spring Security, and CI/CD workflows.

Completed the **790-hour TIC/Software Full-Stack Residency at Serratec**, where I worked on an AI-powered recommendation platform built in partnership with **Zeiss** (OCR, AI pipeline, role-based access control). Also hold a Postgraduate degree in Software Engineering and a background in Industrial Engineering.

Passionate about clean code, problem-solving, and delivering reliable software that creates real value.
