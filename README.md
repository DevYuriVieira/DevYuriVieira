## 🚀 About Me

Full-Stack Software Engineer specializing in **Java (Spring Boot, Virtual Threads)**, **.NET / C# (ASP.NET Core)**, and modern frontend/mobile with **TypeScript (React, Angular, React Native Offline-First)**. 

- 👨‍🏫 **Former Programming Instructor at SENAI / FAETEC**, teaching programming logic, relational databases (PostgreSQL), OOP in Java, and RESTful API architecture.
- 🏢 **Zeiss AI Recommendation Platform:** Delivered an enterprise-grade MVP in partnership with **Carl Zeiss Vision** during the 790-hour Serratec Software Residency (OCR + RAG AI pipeline via n8n, 3-tier JWT/RBAC, dynamic sales analytics).
- ⚙️ **Distributed Systems & Event-Driven Architecture:** Proven experience implementing the Transactional Outbox pattern, RabbitMQ (DLQ/TTL queues), Keycloak OIDC, PostgreSQL concurrency (`FOR UPDATE SKIP LOCKED`, RLS), and distributed tracing with OpenTelemetry.
- 🎯 **Production Excellence:** Built commercial software scoring a perfect **100/100 in all Google Lighthouse categories**, backed by strict end-to-end testing (Vitest, Playwright, Cypress, xUnit, JUnit, k6).
- 🎓 **Education:** Postgraduate degree in Software Engineering and Bachelor's in Industrial Engineering. Advanced English (B2+).
